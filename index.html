맞춤학습

내 학습 기록(퀴즈 정답률·오답 원인·드릴 오판·모의고사 성적)을 모아 지금 약한 곳과 먼저 할 일을 보여주는 개인화 분석 화면입니다. 각 카드의 버튼을 누르면 해당 학습 화면으로 바로 이동합니다.

  • 오답 패턴 분석 — 최근 7일의 틀린 이유(암기 부족·개념 오해·계산 실수 등 시험별 분류)를 집계해 어떤 공부법이 필요한지 알려줍니다. 태그하지 않은 오답도 자동 추정으로 보완합니다.
  • 취약 진술 추적 — O/X·ㄱㄴㄷ 조합 드릴에서 반복해서 오판한 진술을 텍스트로 보여주고, 같은 개념 구간의 연쇄 오판도 감지합니다.
  • 학습 리듬 — 오늘 목표 달성률·주간 학습일·시험 D-day를 추적하고, 주간 정답률 변화와 시험일까지의 페이스를 판정합니다.
  • 단원별 취약 분석 — 오답을 교재 단원으로 매핑해 과목별로 "어느 단원이 약한지" 보여줍니다 (과락은 과목 단위 평가이므로).
  • 합격 갭 분석 — 예상 점수와 합격선의 거리, 최우선 보강 과목을 진단해 다음 행동으로 바로 연결합니다.
  • 과목별 상태·히트맵 — 과목별 진도와 정답률을 색으로 비교해 취약 과목을 한눈에 찾습니다.
  • 성적 추이·합격 예측 — 모의고사 이력으로 점수 추세·과락 위험·예상 점수를 진단합니다.

기록이 쌓일수록 정확해집니다 — 퀴즈·오답 복습·드릴·모의고사를 진행하면 분포·히트맵·예측이 자동으로 채워집니다.

앱 설치하기

사용 중인 브라우저에서 아래 순서로 설치하세요.

  1. 1 브라우저의 메뉴 버튼(⋮ 또는 ≡)을 누르세요. (보통 주소창 오른쪽 또는 화면 하단에 있습니다)
  2. 2 메뉴에서 "앱 설치" 또는 "홈 화면에 추가"를 선택하세요.
  3. 3 확인 팝업에서 "설치"를 누륮면 홈 화면에 추가됩니다.

브라우저별 메뉴 위치:
· Chrome: 주소창 오른쪽 ⋮
· Samsung Internet: 화면 하단 ≡ → "페이지를 홈 화면에 추가"
· Whale/기타: 주소창 주변 메뉴 버튼
주소창에 아이콘이 보이면 바로 눌러도 됩니다.

Safari에서 아래 순서로 설치하세요.

  1. 1 화면 하단의 공유 버튼을 누르세요.
  2. 2 메뉴를 아래로 스크롤해 "홈 화면에 추가"를 선택하세요.
  3. 3 오른쪽 상단의 "추가"를 누륮면 완료됩니다.

iOS는 Safari에서만 홈 화면 추가가 가능합니다.

브라우저 메뉴에서 설치 옵션을 찾아주세요.

Chrome: 메뉴(⋮) → "앱 설치" / Safari(Mac): 파일 → "홈 화면에 추가"

현재 인앱 브라우저에서 열려 있습니다

카카오톡·Instagram·Facebook 등 인앱 브라우저에서는 앱 설치가 지원되지 않습니다. Chrome 브라우저에서 열어주세요.

  1. 1 현재 화면 우측 상단 메뉴(⋮ 또는 ≡)를 누르세요.
  2. 2 "다른 브라우저로 열기" 또는 "Chrome으로 열기"를 선택하세요.
  3. 3 Chrome에서 다시 이 페이지를 열고, 주소창 옆 설치 아이콘 또는 메뉴(⋮) → "앱 설치"를 누르세요.

## 파일 위치

```
audiobook/mp3/
├── understanding/    ← 1과목 (7개)
├── safety/           ← 2과목 (5개)
├── manufacturing/    ← 3과목 (5개)
└── law/              ← 4과목 (2개)
```

각 과목 폴터 바로 아래에 **최종 병합 MP3**가 있고, `ch{NN}_chunks/` 서브폴터에는 개별 청크 파일들이 있습니다.

## 기술 스택

| 구성 요소 | 기술 |
|---|---|
| TTS | Google Translate TTS (`tts_google_direct.py` — 구형 translate_tts GET 엔드포인트 직접 호출) |
| MP3 변환/병합 | ffmpeg 9.0 (pydub + concat) |
| 텍스트 처리 | `md_chunker` (MD → 청킹) → `script_polisher` (낭독용 정제) |
| 진행 추적 | `.generation_progress.json` (중단 시 재실행하면 이어서 진행) |

### 참고: TTS 엔진 변경 이력

| 엔진 | 결과 |
|---|---|
| gTTS 2.5.4 | ❌ Google 봇 탐지(RPC batchexecute)에 차단 — 즉시 429 |
| Piper-Plus 1.13.0 | ❌ 한국어 음성 모델 없음 (ja_JP/zh_CN만 존재) |
| pyttsx3 / win32com | ❌ Windows 파일 저장 버그 (WinError 2/32/183) |
| PowerShell System.Speech | ✅ 동작하지만 기계음 — 백업용으로 유지 (`--engine pyttsx3`) |
| **Google 직접 호출** | ✅ **채택** — 자연스러운 음성 |

## 재생성 방법

```bash
# 전체 재생성 (기존 파일 삭제 후)
python audiobook/generate_all_mp3.py --engine google

# 특정 과목만
python audiobook/generate_all_mp3.py --subject law --engine google

# 오프라인 PowerShell 음성으로 대체
python audiobook/generate_all_mp3.py --engine pyttsx3

# 청크만 병합 (TTS 재생성 없이)
python audiobook/generate_all_mp3.py --merge-only
```

> **주의**: Google TTS 직접 호출은 비공식 엔드포인트이므로 향후 차단될 수 있습니다.
> 차단되면 `--engine pyttsx3` (기본값, 완전 오프라인)로 대체하세요.

# 복수정답형 시험 대비 학습전략

> **문서 ID**: DOC-REF-01
> **범위**: platform · 판본: none

맞춤형화장품 조제관리사 시험의 **복수정답형(ㄱ·ㄴ·ㄷ 조합형)** 문항을 뚫기 위한 학습 전략.
복수정답형은 단순히 "어려운 문제"가 아니라 **채점 단위가 문항이 아니라 진술(命題)**이라는 점에서
학습법 자체를 바꿔야 하는 유형이다.

> **관련 SPEC ID**: `DR-02~07` (복수정답형 드릴) · `Q-*` (퀴즈 채점) — 문항 스키마는 `QUESTION_SCHEMA_DESIGN.md`

---

## 1. 왜 복수정답형은 학습법이 달라야 하나 — 오차가 곱해진다

일반 단일정답형은 보기 하나만 확실히 알거나 명백한 오답을 소거하면 맞힐 수 있다. **부분적 지식으로도 통과**된다.

복수정답형은 다르다. ㄱ·ㄴ·ㄷ·ㄹ 각 진술을 **독립적으로 옳고 그름을 판정**해야 하고,
**하나만 틀려도 조합 전체가 오답**이다.

진술 하나를 맞게 판정할 확률을 `p`, 문항의 진술 수를 `n`이라 하면,
복수정답형 문항을 통째로 맞출 확률은 대략 `pⁿ`이다.

| 진술 정확도 `p` | 4진술 문항 정답률 `p⁴` |
|---|---|
| 0.80 | 약 41% |
| 0.90 | 약 66% |
| 0.95 | 약 81% |

**"80% 정도 안다"로는 복수정답형에서 절반도 못 건진다.**
진술 단위 정확도를 **0.95 이상**으로 끌어올려야 문항 정답률이 쓸 만해진다.
이것이 아래 모든 전략의 전제다.

---

## 2. 전략 (우선순위 순)

### ① 학습 단위를 "문항"이 아니라 "진술(O/X 원자)"로 전환
문제를 통째로 외우지 말고, 모든 지문을 **참/거짓을 판정할 수 있는 최소 명제**로 쪼갠다.
예: "맞춤형화장품판매업은 지방식약청장에게 신고한다" — 이 한 문장이 학습·복습·채점의 기본 단위가 되어야 한다.

### ② O/X 이진 반복으로 진술 정확도(p) 자체를 올리기
쪼갠 명제를 대량의 참/거짓 문제로 만들어 반복한다.
4지선다 문제집을 푸는 것보다, 같은 지식을 O/X로 수백 개 돌리는 편이 `pⁿ`의 `p`를 직접 끌어올린다.
특히 **"그럴듯한 거짓" 진술**을 많이 섞어야 실제 시험의 함정에 대비된다.

### ③ 오답을 "어느 진술에서 틀렸나"로 분해해 약점 목록 관리
복수정답형을 "이 문제 틀림"으로 넘기면 배우는 게 없다.
**어느 진술을 오판했는지까지 내려가** 약한 진술 리스트를 만들고 그것만 반복한다.
> 플랫폼 연계: 스키마가 `statements[].truth` 구조이므로, 채점 결과의 `perStatement`로
> "ㄴ을 O로 착각함"까지 자동 집계하면 이 분해가 구조적으로 가능하다.

### ④ 숫자·한도·기한·등급에 화력 집중
복수정답형은 정확히 이런 데서 몰린다:
- 배합 한도(%), 사용제한·금지 원료
- 법령상 기한·일수(15일·30일 등), 보고 주기
- 벌칙 금액, 청정도 등급, 보존 연한

이 값들은 "대충 알면" 진술에서 뒤집혀 나온다. **숫자·기준만 모은 별도 카드 덱**을 만들어 따로 암기한다.

### ⑤ 혼동쌍(confusion pair) 대조 학습
거짓 진술은 대개 참 진술의 "한 글자 바꾼 버전"이다. 참 버전만 외우지 말고 **거짓 짝과 나란히 놓고 대조**한다.

| 참 | 흔한 거짓(함정) |
|---|---|
| 신고 | 등록 |
| 식약처장 | 지방식약청장 |
| 처장 | 시·군·구청장 |
| 매년 | 반기 |
| 매년 | 2년 |

### ⑥ 재읽기 대신 능동 인출 + 간격 반복
교재 재독은 "안다는 착각"만 키운다.
답을 가리고 각 진술을 O/X로 스스로 판정 → 확인 → **틀린 원자만 간격을 두고 재출제**하는
능동 인출(active recall + spaced repetition)로 전환한다. (전략 ②·③이 이를 자연스럽게 강제한다.)

### ⑦ 시험장 전술 — 확실한 거짓으로 조합 소거
모든 진술을 알 수 없을 때, **가장 확실한 진술 하나에 앵커**를 건다.
- "ㄴ이 거짓임이 확실" → ㄴ이 **포함된** 선택지를 전부 소거
- "ㄱ이 참임이 확실" → ㄱ이 **빠진** 선택지를 전부 소거

확실한 1~2개만으로 5지선다가 2지선다로 줄어드는 경우가 많다.

### ⑧ 과락 관점의 시간 배분
과목별 **40% 과락**이 있으므로, 복수정답형·숫자가 밀집한 과목
(제조 및 품질관리 / 유통화장품 안전관리 / 맞춤형화장품의 이해)에 무게를 두되,
**어느 과목도 40% 밑으로 두지 않는다.**
> 참고: 변환한 복수정답형 풀(755문)에서 과목3은 사실상 전부 선다형이라 O/X 전환 효과가 특히 크다.

---

## 3. 핵심 요약

> **"문항을 푼다"에서 "진술을 참/거짓으로 확정한다"로 학습의 최소 단위를 내리는 것**이
> 복수정답형 대비의 핵심이다.

진술 정확도 `p`를 0.95+로 올리면 4진술 문항 정답률이 41% → 81%로 뛴다.
그 `p`를 올리는 가장 빠른 길이 **O/X 이진 드릴 + 진술 단위 오답 추적**이다.

## 4. 플랫폼 적용 포인트 (Cosmetic Pass Master) — 적용 완료

위 전략은 스마트 훈련소의 드릴 체계로 전량 구현됐다. 전략별 대응 기능:

| 전략 | 구현 |
|---|---|
| ① 진술 원자 | O/X 드릴(3,700+문) — 문항=진술. 복수정답형은 진술별 O/X 토글·판정·해설 |
| ② 이진 반복 | 과목별·전 과목 O/X 세션 (출제 수 10/20/전체) |
| ③ 오판 분해·약점 목록 | `statement_stats` + 취약 진술 리뷰 패널. '취약·복습 진술만' 드릴(`weak` 모드). 연속 정답 3회 졸업 |
| ④ 숫자·기준 카드 덱 | '수치·한도·기한 집중' 드릴(`num` 모드) — `inferTags`가 STANDARD_TAGS 자동 부여 |
| ⑤ 혼동쌍 대조 | `conceptId`(교재 L#### 클러스터) 그룹핑 → 참/거짓 진술 2단 대조 배치 |
| ⑥ 능동 인출+간격 반복 | 2단계 응시(전 진술 판정 → 조합 도출) + SM-2 기한 도래 우선 편성 |
| ⑦ 확실한 거짓 소거 | 부분 판정과 모순되는 선지 실시간 흐림 + "선지 N개 소거" 힌트 |
| ⑧ 과락 시간 배분 | 대시보드 취약 과목 추천 + 모의고사 (드릴 범위 밖) |

데이터 기반: `perStatement.judgedCorrect` → `sid` 단위 오판 통계 + SM-2 큐 누적
(상세 파이프라인: [`QUESTION_SCHEMA_DESIGN.md`](../design/QUESTION_SCHEMA_DESIGN.md) §6).

## 1. 조사 목적과 범위

- **조사 기준일**: 2026-09-25
- **조사 대상**: 국내 맞춤형화장품판매업 신고(추정 포함) 업소 및 관련 솔루션 공급사
- **조사 방법**: 공개 웹 자료(언론 보도, 공급사·협회 홈페이지, 자사몰) 기반 탐색 조사
- **용어 정의**
  - *신고 업소*: 식약처 신고 현황 또는 신뢰 가능한 자료로 맞춤형화장품판매업 신고가 확인된 업소
  - *실제 영업 업소*: 신고 여부와 별개로 현재 영업이 확인되는 업소 — **신고 ≠ 영업**. 신고 후 폐업·휴업한 업소가 명부에 남을 수 있음
- **조사 한계**: 신고번호를 공개한 독립 업소가 극히 드물어, 공식 명부 확보 전까지 모집단의 규모·구성은 미확정이다. 공급사 기능 비교는 공개 자료 기준이며 "공개 자료에서 확인되지 않음"과 "실제 기능 부재"는 구분해야 한다.

## 2. 핵심 결론

### 확인된 사실

- 신고 업소 수 추이(공개 보도 기준): 2020년 6월 58곳 → 2021년 6월 150곳 → 2023년 말 231곳
- 공개된 공급사(릴리커버·비컨)는 '진단→추천→조제' 흐름의 앞단 중심. 판매내역서·원료목록 보고·제조번호 추적 같은 법정 기록을 대표 기능으로 내세운 곳은 공개 자료에서 확인되지 않음
- 조제관리사 누적 합격자 6,796명(2025년 초) 대비 신고 업소는 약 3% 규모 — 자격 취득자 대부분은 책임판매관리자 등으로 진출하고 판매업 창업은 소수
- 판매업자의 핵심 법정 기록 의무(판매내역서 작성·보관, 원료목록 연 1회 보고)는 1차 법령으로 검증 완료 — §8 참조

### 미확인 사항

- **2026년 공식 신고 수**: 사업기획서 추정치 약 225곳은 산출 근거·집계 기준이 미확인. 공식 명부 확보 전까지 시장 규모의 확정값으로 사용 금지
- 각 시점 수치의 집계 기준 동일성 → **시장의 성장·정체 여부 판단 보류** (2023년 231곳 → 2026년 약 225곳을 '감소'로 해석하면 위험)
- 독립 소형 업소 비율 및 규모 (§3 모집단 분류 참조)
- 공급사 솔루션의 법정 기록 기능 실제 제공 여부
- 2025년 11월 식약처 행정명령의 구체 내용(대상·조치 항목)

### 주요 가설 (인터뷰 검증 대상)

- **가설 A**: 장비 없이 수기·엑셀로 법정 기록을 관리하는 독립 소형 업소에 기록 도구의 유료 수요가 있다. — *"기능 공백"은 "유료 수요"를 입증하지 않음. 불편과 지불 의사는 별개로 측정해야 함*
- **가설 B**: 2027.4.29 개정법 시행으로 소분 전용 매장이 늘어 기록·교육 수요가 확대된다. — *'리필 진입 증가'와 '기록 도구 수요 증가'는 별개의 가설*
- **가설 C**: 신고 업소 중 독립 소형 업소 비율이 30~50%이다. — *근거 없는 추정, 공식 명부 분류로 검증 필요*
- **가설 D**: 소형 화장품책임판매업자(생산실적·원료목록 보고, 책임판매관리자 교육 — 즉시 유효 + 안전성 평가 자료 작성 의무는 소형 기준 2031.1.1 도입)에도 기록·보고 도구 수요가 있다. — *1차 타깃(맞춤형 판매업소)과 별개인 확장 세그먼트 가설. 안전성 평가는 단기 동인이 아니라 장기 촉매. §4-1 참조*

### 다음 검증 과제

1. 의약품안전나라·정보공개청구로 공식 신고 명부 확보 (P0)
2. 명부 기준 독립 소형 업소 분류로 잠재 모집단 산출 (P0)
3. 공식 명부의 2026년 신고 수로 225곳 추정치 재검증 (P0)
4. 인터뷰로 현재 기록 방식·업무량·오류·비용·지불 의사 측정 (P1)
5. 공공데이터 API로 대전·세종·오송 책임판매업 모집단 산출, 2026.10.22~24 오송화장품뷰티엑스포 현장 접촉 (P1 — **시한성**: 엑스포까지 약 1개월, §4-1)

**해석:** 공개 자료에서 확인되는 판매업소 신고 수는 2020년 58곳, 2021년 150곳, 2023년 말 231곳으로 나타난다. 다만 각 수치의 집계 기준과 2026년 추정치의 산출 근거가 동일한지 확인되지 않아, 현재 시장의 성장·정체 여부는 공식 최신 자료를 통해 재검증해야 한다. 합격자 대비 신고 업소 수 비율은 약 3%로, 자격 취득자 대부분은 책임판매관리자 등으로 진출하고 판매업 창업은 소수라는 뜻이다.

### 명부 확보 경로

- 의약품안전나라(nedrug.mfds.go.kr) 신고 현황 조회, 필요시 정보공개청구 — 확보한 상호·소재지 목록이 접촉 기록표의 분모가 된다
- 두 협회(§7)와 리필 매장·공급사 네트워크는 명부의 보조 수단

## 4-1. 지역 조사: 대전·세종·오송 화장품 책임판매·제조업체 (2026-09-25 추가)

### 조사 범위와 전제

- **업종 구분 주의**: 화장품책임판매업은 식약처 **등록**(화장품법 제3조①), 맞춤형화장품판매업은 **신고**(제3조의2①)로 별개 업종이다. 이 절의 업체는 §4의 맞춤형 판매업소 모집단에 포함하지 않는다.
- **Formula OS와의 관계**: ① 맞춤형 판매업소가 혼합·소분하는 내용물을 공급하는 쪽이 책임판매업자이므로, 지역 판매업소의 **공급망·파트너 후보**이다. ② 책임판매업자도 생산실적 보고(다음 해 2월 말), 원료목록 보고(유통·판매 전), 책임판매관리자 연 1회 교육 의무가 있고(식약청 등록 안내, 미보고 과태료는 법정 100만 원 이하 — 부과 기준액 50만 원 안내는 시행령 별표 기준 미검증), 안전성 평가 자료 작성 의무는 규모·유형별로 2028~2031년 단계 도입(10억 원 미만 소형은 2031.1.1)된다 → 별도 가설 D(§2)로만 다룬다.
- **관할**: 대전·세종·충남·충북은 대전지방식품의약품안전청 관할(신고·등록 민원 창구). 식약처 본부는 오송(청주시 흥덕구 오송읍)에 있다.
- **규모 참고**: 식약처 원자료를 재가공한 민간 포털 기준 전국 제조업+책임판매업 등록 건수는 약 3만 2천여 건(제조·책임판매 중복 등록 포함, 기준일·폐업 반영 여부 미확인). 지역별 책임판매업 수는 **미확인** — 공식 API로 산출 필요.

### 지역 맞춤형 판매업소 후보 (§4 등급 기준 적용)

이번 조사에서 대전·세종·오송에서 맞춤형화장품판매업 **신고가 확인된 업소는 찾지 못했다.** 향수는 화장품(방향용 제품류)이므로, 고객 맞춤 향수를 조제·판매하는 공방은 신고 대상 여부 확인이 필요한 후보다(§4 #1 마계공방과 같은 유형).

| 업소명 | 지역 | 서비스 | 온라인 채널 | 분류 |
|---|---|---|---|---|
| 퍼퓸플레이 | 대전 중구 은행동(성심당 맞은편) | 니치 향 블렌딩 시그니처 향수 만들기 | 지역 상권 플랫폼 게재 | C (향수 취급 확인, 신고 미확인) |
| 냄시(naem_sih) | 대전 중구 은행동 | 향수·디퓨저·캔들 공방, 네이버 예약제 | 인스타그램 @naem_sih | C |

단, 맞춤형화장품판매업 신고 대상은 고객 맞춤으로 내용물을 **혼합·소분해 판매**하는 경우이므로(제2조제3호의2), 단순 체험·재료 판매 중심 공방은 해석이 다를 수 있다 — 접촉 시 영업 형태부터 확인.

### 명부 확보 경로 (이 절)

1. **공공데이터포털 '식품의약품안전처_화장품 관련 정보' Open API**(data.go.kr/data/15020628) — 제조업·책임판매업 업체 정보 제공. 주소 필드로 '대전광역시', '세종특별자치시', '청주시 흥덕구 오송읍'을 필터링해 지역 모집단 산출 (P1)
2. 의약품안전나라 업체정보 조회(nedrug.mfds.go.kr) — 개별 업체의 등록 업종 확인으로 R-B → R-A 상향

### Formula OS 관점 정리

- **1차 타깃 불변**: 책임판매업자는 맞춤형 판매업소와 의무 구조가 달라 §7 인터뷰 분모(10곳)에 넣지 않는다.

### 실제 경쟁군 (대체재)

전문 공급사 외에 실제 고객이 쓰는 도구가 진짜 경쟁 상대입니다 — 독립 업소가 이미 엑셀이나 POS로 기록하고 있다면 경쟁자는 진단기기가 아니라 그 범용 도구입니다.

| 경쟁 유형 | 예시 | 경쟁 의미 |
|---|---|---|
| 전문 진단·조제 솔루션 | 릴리커버, 비컨 등 | 장비·진단·조제 중심. 법정 기록 기능은 공개 확인 안 됨(부재 확정 아님) |
| 범용 업무도구 | 엑셀, 구글시트 | 저비용 기록 관리. 독립 업소의 현재 표준일 가능성 — 인터뷰 필수 확인 항목 |
| 수기 관리 | 종이 장부, 파일철 | 가장 낮은 도입 장벽, 가장 흔한 현 상태일 가능성 |
| 기존 POS·ERP | 매장별 사용 시스템 | 판매·재고 기록의 대체재 |
| 자체 개발 시스템 | 대기업·대형 업소(아모레, 톤28) | 맞춤형 업무 통합 — 초기 타깃 아님 |
| 규제·품질관리 대행 | 외부 컨설팅·대행사 | 전문 업무의 외주화 |

**해석:** 공개된 공급사는 모두 '진단→추천→조제' 앞단을 팝니다. 판매내역서·제조번호 추적·연 1회 원료목록 보고 같은 뒷단 컴플라이언스를 대표 기능으로 내세운 곳은 공개 자료에서 확인되지 않습니다 — 단 이것은 "기능이 없다"의 확정이 아니라 "공개적으로 확인되지 않는다"는 뜻입니다(공급사 인터뷰로 직접 확인 필요). Formula OS는 장비 공급사와 경쟁하기보다, 장비 없이 수기·엑셀로 운영하는 독립 업소를 겨냥하는 편이 차별화에 유리합니다.

## 6. 고객 문제 가설

Formula OS가 대체하려는 업무(§8 법정 의무): 판매내역서 작성·보관, 원료·제조번호 추적, 연 1회 원료목록 보고, 교육·점검 대응, 한시적 영업 신고.

단, 기능 공백만으로 유료 수요가 입증되지 않으므로 인터뷰에서 다음을 별개로 측정해야 합니다 — **'불편하다'와 '돈을 내고 해결할 만큼 중요하다'는 다른 검증 항목**입니다.

| 검증 항목 | 확인할 질문 |
|---|---|
| 현재 업무 | 판매내역서를 어떤 방식으로 작성하는가? (수기/엑셀/POS/공급사 시스템) |
| 빈도 | 하루·주·월 몇 건의 기록을 작성하는가? |
| 소요 시간 | 기록 1건에 몇 분이 걸리는가? |
| 오류 | 누락·중복·수정 문제가 발생한 적이 있는가? |
| 보관 | 기록을 어디에 얼마나 오래 보관하는가? |
| 원료관리 | 원료와 제조번호를 어떻게 추적하는가? |
| 보고 | 원료목록 보고를 누가, 어떤 방식으로 처리하는가? |
| 비용 | 현재 사용하는 프로그램·장부·외주 비용은 얼마인가? |
| 구매 의사 | 어떤 기능이 있으면 유료로 사용할 의향이 있는가? — 지불 의사는 문제 강도와 별도 측정 |

| 교육 의무 | 조제관리사는 안전성·품질관리 교육을 매년 이수 (최초 교육: 종사일로부터 6개월 이내, 보수교육: 매년 1회) | 법 제5조⑦ + 시행규칙 제14조 |
| 소비자 설명 의무 | 혼합·소분된 내용물·원료의 내용과 특성, 사용상 주의사항을 판매 시 소비자에게 설명 | 시행규칙 제12조의2 4호 |
| 부작용 보고 | 사용 관련 부작용 발생사례를 식약처장에게 보고 | 시행규칙 제12조의2 5호 |
| 한시적 영업 | 신고 소재지 외 장소에서 **1개월의 범위**에서 한시적 영업 시 신고서 + 신고필증·자격증 사본 첨부 | 시행규칙 제8조의2① |
| 변경신고 | 총리령상 신고사항 변경 시 변경신고 의무 | 법 제3조의2① 후단 + 시행규칙 제8조의3 |

### 시행 예정 사항

- **법률 제21604호(2026.4.28 공포, 2027.4.29 시행)**: 제3조의2② 단서 신설 — 소분 화장품(제2조제3호의2나목 본문) 중 총리령으로 정하는 화장품만 판매하는 매장은 조제관리사 대신 소분 교육 이수 종업원을 둘 수 있음. 교육은 ①화장품 관련 법령 ②소분 시 안전·위생관리 ③총리령상 사항을 포함해야 함(제3조의2③). 해당 종업원도 제5조⑦의 연간 교육 의무 대상에 추가됨. 대한맞춤형화장품조제관리사협회(kpcda)는 개정안 반대 서명을 요청한 바 있음
- **법률 제21302호(2025.12.30 공포, 2026.12.31 시행)**: 책임판매업자의 화장품 안전성 평가 자료 작성·보관 의무 도입(제4조의2 신설). 단, 의무 적용은 업체 규모·유형별 **단계 시행** — 연 생산액·수입액 10억 원 이상 또는 법 공포 후 신규 등록 업소는 기능성화장품 심사·보고 제품 판매 시 2028.1.1, 최초 제조·수입 출시 제품은 2030.1.1, 기타는 2031.1.1. **10억 원 미만 업소는 2031.1.1**. 2026.12.31에 실제 시행되는 것은 화장품안전정보센터 지정 등 지원 인프라(제18조의3~5, 제33조의3)로, 평가 의무 자체는 아님
- **법률 제21709호(2026.5.26 공포, 2026.11.27 시행)**: AI로 만든 전문가 오인 광고 금지

### 미확인 사항

- 개정법의 시행령·시행규칙 세부사항: 적용 대상 화장품 범위("총리령으로 정하는 화장품"), 교육기관·방법·이수증 발급 주체(제3조의2④ 총리령 위임), 기존 신고 업소에 미치는 영향
- 과태료 부과 기준액(50만 원이라는 서울지방식약청 안내는 시행령 별표 기준 확인 필요)
- 2025년 11월 식약처 행정명령의 구체 내용 — 협회 공지로 존재만 확인. 법 제5조⑧(식약처장이 영업자에게 교육을 명할 수 있음)이 법적 근거 후보이나, **인터뷰 때 업소에 직접 확인해야 할 핵심 항목**
- 한국맞춤형화장품조제관리사협회 조제관리사 실태조사(2026.8.20 공지) 결과 — 미공개. 공개되면 합격자→실무 전환율 근거로 활용

### Caveats

- 대부분 업소의 신고번호는 공개 웹에서 확인하지 못했습니다. 표의 '미확인'은 미신고가 아니라 **근거 미발견**이라는 뜻입니다.
- 조사 상태 분류(A~E)는 공개 자료 기준의 현재 스냅샷이며, 공식 명부 확보 후 갱신이 필요합니다.

- §4-1의 공장등록 자료는 산업집적법상 공장 등록 현황이며 화장품법상 업 등록과 다릅니다. 폐업·이전이 반영되지 않았을 수 있습니다.

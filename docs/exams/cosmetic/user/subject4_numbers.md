## 암기 우선순위

### ⭐ 최우선 (출제 빈도 최상)

1. **결격사유** — 판매업 1년 / 조제관리사 3년
2. **자격시험 합격 기준** — 전 과목 60% / 매 과목 40% 이상
3. **각화 주기** — 28±3일
4. **모발 성장주기** — 성장기 3~6년(80~90%), 퇴행기 3주, 휴지기 3~4개월
5. **각질층 구성** — 케라틴 58%, NMF 31%, 지질 11%
6. **안정성 시험** — 3로트 이상 · 6개월 이상 · 4종

### ⭐ 차순위

7. **교육** — 최초 6개월, 보수 매년 1회 4~8시간
8. **변경신고** — 30일, 처리 10일/7일
9. **모발 성장 속도** — 0.3~0.5mm/일, 50~100가닥 탈락
10. **콜라겐** — 피부 건조 중량 75%, 아미노산 1,000개

### ⭐ 참고

11. **포장공간** — 세정 15%, 기타 10%, 종합 25%
12. **안전성 시험 9종** — 명칭 암기
13. **NMF 구성** — 아미노산 40%, PCA 12%, 젖산염 12%, 요소 7%

## 암기 팁

| 팁 | 내용 |
|------|------|
| **결격 짝꿍** | 판매업 1년 vs 조제관리사 3년 — 짧/긴 대비 |
| **성장주기 3단계** | 성장기(3~6년, 80~90%) → 퇴행기(3주) → 휴지기(3~4개월) |
| **각질층 3성분** | 케라틴 58 + NMF 31 + 지질 11 = 100% |
| **안정성 4종** | 장기·가속·가혹·개봉후 — 공통 3로트/6개월 |
| **포장공간 3종** | 세정 15% > 종합 25% > 기타 10% (상한) |
| **본문 교차 확인** | 숫자 암기표 + 본문 📊 비교표 함께 학습 |

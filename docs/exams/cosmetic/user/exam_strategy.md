## 과목별 공략법

### 1과목: 화장품법의 이해 (10문항, 10%)

#### 특징
- 문항 수가 적어 **1문제당 영향력이 큼** (1문제 = 전체 1점 = 과목 10%p)
- 암기 위주. 법령 체계와 숫자가 핵심.
- 10문항 중 4문항(40%) 정답이면 과락 면피

#### 핵심 주제
1. **화장품법 목적·법령 체계** — 법 → 시행령 → 시행규칙 → 고시
2. **화장품 정의** — 의약품과의 구분 (효능·효과 표시 경계)
3. **영업 3종** — 제조업, 책임판매업, 맞춤형화장품판매업 구분
4. **행정처분 및 벌칙** — 시정명령(별도), 행정처분 3종(과징금, 업무정지, 면허취소)
5. **개인정보 보호법** — 고객정보 입력·관리·상담, 과태료 vs 벌칙

#### 빈출 포인트
- ⭐ **영업 3종 비교표** — 가장 빈출. 허가 주체, 영업 범위, 결격사항 구분
- ⭐ **벌칙 금액** — 1년 이하 징역/1천만원 벌금, 3년 이하 징역 등
- ⭐ **과징금 상한** — 10억원 (매출액 2% 이내)
- ⭐ **개인정보 과태료 vs 벌칙** — 헷갈리기 쉬운 함정 문제

#### 학습 전략
- 교재 `1.cosmetic-law.md`의 **📊 영업 3종 비교표** 완벽 숙지
- `2.privacy-law.md`의 **📊 과태료 vs 벌칙 비교표** 암기
- 숫자 암기: 벌칙 금액, 과징금, 업무정지 일수
- **목표**: 4/10 (과락 면피) → **안정권 6/10**

### 2과목: 화장품 제조 및 품질관리 (25문항, 25%)

#### 특징
- 원료 지식 + 제조 공정. **범위가 넓고 숫자 암기 다수**.
- 별표 2 (사용제한 원료)가 가장 빈출.
- 25문항 중 10문항(40%) 정답이면 과락 면피

#### 핵심 주제
1. **원료 분류** — 기질/기능성, 승인/제한/금지
2. **계면활성제 4종** — 음이온/양이온/비이온/양성
3. **기능성화장품 심사** — 심사대상 vs 보고대상 (보고서 제출 시 15일 처리) 구분
4. **사용제한 원료 (별표 2)** — ⭐ 가장 빈출 영역
5. **제조관리 기준, CGMP 4대 기준**
6. **위해사례 판단·보고 의무**

#### 빈출 포인트
- ⭐ **별표 2 사용제한 원료 한도** — 페녹시에탄올 1.0%, 벤조익애씨드 0.5%, 살리실릭애씨드 0.5%, 티타늄디옥사이드 25.0% 등
- ⭐ **보존제/자외선차단제 한도 표** — 숫자 암기 필수
- 계면활성제 4종 HLB값, 용도 구분
- 위해성 등급별 보고 의무 (중증/경증/기타)

#### 학습 전략
- 교재 `3.restricted.md`의 **📊 보존제 주요 사용한도 비교표** + **📊 자외선 차단 성분 주요 사용한도 비교표** 암기
- `1.ingredients.md`의 **📊 계면활성제 4종 비교표** + **📊 유성 원료 7종 비교표**
- `5.hazard.md`의 **📊 위해성 등급 비교표** — 보고 의무 구분
- 숫자 암기 중심 → 플래시카드 SM-2 간격 반복 활용
- **목표**: 10/25 (과락 면피) → **안정권 15/25**

### 3과목: 유통화장품 안전관리 (25문항, 25%)

#### 특징
- 실무 위생관리. **직접 조제 관련 가장 실전에 가까운 과목**.
- 소독, 청정도, 미생물 한도 등 환경 기준이 핵심.
- 25문항 중 10문항(40%) 정답이면 과락 면피

#### 핵심 주제
1. **작업장 위생관리** — 청정도 등급, 에어필터, 소독
2. **작업자 위생관리** — 소독 절차, 복장 기준
3. **설비·기구 관리** — 세척, 판정, 저울 점검
4. **내용물·원료 관리** — 미생물 허용한도, 폐기 기준
5. **포장재 관리** — 1차/2차 포장, 안전용기, 사용기한

#### 빈출 포인트
- ⭐ **청정도 등급** — 1등급(무균실, H/E) → 2등급 → 3등급 → 4등급(일반, P/F) 구분
- ⭐ **미생물 허용한도** — 일반 1,000개/g, 영유아·눈화장 500개/g 이하
- ⭐ **소독제 6종** — 에탄올, 크레졸, 차아염소산, 페놀, 벤잘코늄, 글루콘산
- ⭐ **중금속 한도** — 납 20·비소 10·수은 1·안티몬 10·카드뮴 5㎍/g
- 위해성 등급 3단계 — 1등급(중대, 즉시 회수명령) → 2등급(회수권고) → 3등급(자발적 회수)
- 낙하균 측정 — Koch법, 5분 노출

#### 학습 전략
- 교재 `1.workspace-safety.md`의 **📊 청정도 등급 비교표** + **📊 에어 필터 비교표** + **📊 화학적 소독제 비교표**
- `4.material-safety.md`의 **📊 미생물 허용한도 비교표** — 숫자 암기
- `5.packaging-safety.md`의 **📊 1차·2차 포장 비교표** + **📊 안전용기 대상 품목 비교표**
- 중금속·유해물질 한도 표 → 숫자 암기
- **목표**: 10/25 (과락 면피) → **안정권 15/25**

### 4과목: 맞춤형화장품의 이해 (40문항, 40%)

#### 특징
- **최대 비중 (40%)**. 합격을 좌우하는 핵심 과목.
- 범위가 가장 넓고 출제 비율이 가장 높음.
- 40문항 중 16문항(40%) 정답이면 과락 면피

#### 핵심 주제
1. **맞춤형화장품 정의·규정** — 혼합형 vs 소분형, 판매업 vs 조제관리사
2. **피부·모발 생리구조** — 표피 5층, 진피 2층, 모발 성장주기
3. **관능평가 방법·절차** — 맹검/비맹검, 관능 용어
4. **제품 상담** — 부작용, 배합금지, 사용제한
5. **표시사항** — 1차(용기)/2차(갑)/소용량(1회량) 포장
6. **혼합·소분 도구·기기** — 호모게나이저, 디스퍼, 충진기
7. **충진·포장 방법**

#### 빈출 포인트
- ⭐ **맞춤형화장품 정의** — 혼합형(내용물+내용물/원료) vs 소분형(고형비누 단순소분 제외) 구분
- ⭐ **표피 5층 구조** — 기저층, 유극층, 과립층, 투명층, 각질층 (순서·기능)
- ⭐ **포장 표시사항** — 1차(용기), 2차(갑), 소용량(1회량) 필수 표시 항목 구분
- ⭐ **혼합·소분 도구** — 호모게나이저(고속 균질), 디스퍼(저속 혼합) 용도 구분
- 안전성시험 9종 vs 안정성시험 4종 구분
- 중금속·유해물질 검출 허용한도 (납, 비소, 카드뮴, 수은, 안티몬)
- 모발 성장주기 (성장기/퇴행기/휴지기) 기간
- 자외선 종류 (UVA, UVB, UVC) 파장·특성

#### 학습 전략
- 교재 `1.overview.md`의 **📊 맞춤형화장품 혼합형 vs 소분형 비교표** + **📊 맞춤형화장품판매업 결격사유 vs 조제관리사 결격사유 비교표**
- `2.physiology.md`의 **📊 표피 5층 구조 비교표** + **📊 모발 성장주기 비교표** + **📊 자외선 종류 비교표**
- `5.guideline.md`의 **📊 1차 vs 2차 vs 소용량 포장 표시사항 비교표**
- `6.mixing-subdivision.md`의 **📊 호모게나이저 vs 디스퍼 비교표** + **📊 pH 범위 비교표**
- `7.filling-packaging.md`의 **📊 충진기 종류 비교표** + **📊 포장공간 비율·횟수 비교표**
- 범위가 넓으므로 **비교표 중심 암기** → 플래시카드 적극 활용
- **목표**: 16/40 (과락 면피) → **안정권 24/40**

## 앱 내 학습 추천 순서

### 1단계: 교재 읽기 (기본 이론)
- **4과목 → 2과목 → 3과목 → 1과목** (비중 역순)
- 각 단원의 `🎯 최우선 암기 축` + `🔢 숫자 암기 미리보기` 먼저 확인
- `📊 비교표` 중심 학습 — 표 하나당 1문제 출제 가능성

### 2단계: 플래시카드 (암기 정착)
- SM-2 간격 반복 학습으로 숫자 암기 정착
- 난이도 필터: easy/medium/hard 순차 진행
- 키보드 Enter/Space로 빠른 회전

### 3단계: 기출 퀴즈 (출제 패턴 파악)
- 과목별 기출 퀴즈 풀이
- 오답은 자동으로 오답 노트에 누적
- 키보드 단축키 1-5 (객관식), o/p (OX) 활용

### 4단계: 모의고사 (실전 대응)
- 100문항 통합 모의고사로 시간 관리 연습
- 과목별 정답률 히트맵으로 약점 시각화
- 과락 위험 과목 자동 추천 → 집중 재학습

### 5단계: 오답 복습 (약점 보완)
- 과락 위험 과목 집중 재학습
- 오답 노트에서 "제외" 기능으로 확실히 암기한 문제 정리
- 대시보드 "오늘 복습" 카드로 간격 반복 유지

각 과목 교재 말미의 `⚡ 시험 직전 체크리스트` + `🧠 30초 회상` 활용:

- [ ] 1과목: 영업 3종(제조업·책임판매업·맞춤형판매업), 법령 4단 체계, 시정명령(별도)+행정처분 3종(업무정지·등록취소·과징금), 결격사유, 기능성화장품 11가지, 천연/유기농 기준, 표시·광고 규제(의약품·기능성 오인·거짓·과장), 개인정보 4종 분류, 안전성 정보 보고(15일)·위해평가 정기검토(5년)
- [ ] 2과목: 원료 4대 분류, HLB 0~20, 계면활성제 4종, 보존제 한도(페녹시에탄올 1.0%·벤조익애씨드 0.5%·살리실릭애씨드 0.5%·티타늄디옥사이드 25%), 자외선차단제 SPF·PA 기준, 사용금지·제한 원료(별표 1/2), 제조공정(원료→배합→제조→충진·포장→출하), CGMP 3대 요소·5장, 알레르기 유발성분 25종
- [ ] 3과목: 중금속 수치(납 20·비소 10·수은 1·안티몬 10·카드뮴 5㎍/g), 미생물 한도(일반 1,000·영유아·눈화장 500개/g), 청정도 4등급(1등급 무균실 H/E → 4등급 일반 P/F), 필터 3종(P/F→M/F→H/F), 소독제 6종, 낙하균 Koch법(고청정 30분 이상), 위해성 등급 3단계(가 15일·나/다 30일 이내)
- [ ] 4과목: 맞춤형화장품 정의(혼합형+소분형), 판매업 신고제, 자격시험(60%/40%), 안전성시험 9종, 유효성(효력시험+인체적용시험+SPF/PA), 안정성시험 4종, 피부 5층, 모발 성장주기, 인체적용시험, 혼합·소분 실무(품질성적서→소독→용기→판매내역서), 교육
- [ ] 전체: 60점 목표, 과목당 40점 이상 확인

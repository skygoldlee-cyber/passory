## 암기 우선순위

### ⭐ 최우선 (출제 빈도 최상)

1. **보존제 한도** — 페녹시에탄올 1.0%, 파라벤 0.4%/0.8%, 살리실산 0.5%
2. **자외선차단제 한도** — 벤조페논-3 2.4%, 티타늄디옥사이드 25%
3. **기능성화장품 유효성분** — 나이아신아마이드 2~5%, 아데노신 0.04%, 레티놀 2,500IU/g
4. **HLB값** — 3~6 (W/O), 8~18 (O/W)
5. **SPF·PA 등급** — PA+ ~ PA++++ 구분

### ⭐ 차순위

6. **향수 부향률** — 향수 15~20%, 오드뚜왈렛 5~10%, 오드코롱 3~5%
7. **중금속 한도** — 납 50/20㎍/g
8. **알레르기 표시 기준** — 0.01%/0.001%
9. **위해 보고 기한** — 15일/즉시

### ⭐ 참고

10. **기타** — 트리클로산 0.3%, 치오글리콜산 11%(퍼머)/3~4.5%(제모), AHA 10%/pH 3.5

## 용어·약어 사전

### 법령·제도

| 약어/용어 | 원문 | 설명 |
|------|------|------|
| **KFCC** | Korean Functional Cosmetics Code | 기능성화장품 기준 및 시험방법 (식약처 고시). 별표 1~10으로 구성. |
| **CGMP** | Cosmetics Good Manufacturing Practice | 화장품 우수제조 및 품질관리기준. 제조업소 의무 적용. |
| **안전기준** | 화장품 안전기준 등에 관한 규정 | 식약처 고시. 사용금지·제한원료, 중금속·미생물 기준 포함. 별표 1~4. |
| **시행규칙** | 화장품법 시행규칙 | 화장품법 하위 규칙. 별표 1~9 (행정처분, 품질관리, 포장표시 등). |
| **별표 1** | (안전기준) 사용불가원료 | 화장품에 사용 금지된 원료 목록 |
| **별표 2** | (안전기준) 사용제한원료 | 기준·시험방법이 정해진 원료. 보존제·자외선차단제·염모제 등 사용한도 규정. |
| **별표 3** | (안전기준) 인체세포조직배양액 안전기준 | 세포배양액 원료 안전기준 |
| **별표 4** | (안전기준) 유통안전관리시험방법 | 중금속·유해물질 검출 한도 |
| **식약처** | 식품의약품안전처 | 화장품 관련 법령 고시·심사 주체 |
| **식약처 고시** | 식품의약품안전처 고시 | 법령 하위 규정. KFCC, 안전기준, 색소기준 등. |

### 자외선·SPF

| 약어/용어 | 원문 | 설명 |
|------|------|------|
| **SPF** | Sun Protection Factor | 자외선B(UVB) 차단 지수. SPF 50+ = SPF 50 이상. |
| **PA** | Protection Grade of UVA | 자외선A(UVA) 차단 등급. PA+ ~ PA++++ (4단계). |
| **PPD** | Persistent Pigment Darkening | UVA 차단력 측정법. PA 등급 기준. PA+ 2~4, PA++ 4~8, PA+++ 8~16, PA++++ 16~. |
| **UVB** | Ultraviolet B | 자외선B (280~320nm). 홍반·색소침착 유발. SPF로 차단. |
| **UVA** | Ultraviolet A | 자외선A (320~400nm). 광노화·흑화 유발. PA로 차단. |
| **UVC** | Ultraviolet C | 자외선C (200~280nm). 오존층 흡수, 지표 도달 적음. |
| **산란제** | 무기 자외선차단제 | 티타늄디옥사이드, 징크옥사이드. 입자가 빛을 반사·산란. |
| **흡수제** | 유기 자외선차단제 | 벤조페논-3, 옥토크릴렌 등. 자외선 에너지 흡수→열 변환. |

### 계면활성제·유화

| 약어/용어 | 원문 | 설명 |
|------|------|------|
| **HLB** | Hydrophilic-Lipophilic Balance | 친수-친유 균형값. 3~6: W/O 유화, 8~18: O/W 유화. |
| **W/O** | Water-in-Oil | 유중수형 유화. 유성이 연속상, 수성이 분산상. |
| **O/W** | Oil-in-Water | 수중유형 유화. 수성이 연속상, 유성이 분산상. |
| **미셀** | Micelle | 계면활성제가 일정 농도(CMC) 이상에서 형성하는 구조. 가용화에 이용. |
| **CMC** | Critical Micelle Concentration | 임계 미셀 형성 농도. 미셀이 형성되기 시작하는 최소 농도. |
| **유화** | Emulsification | 서로 섞이지 않는 액체(수성·유성)를 균일하게 분산시키는 공정. |
| **가용화** | Solubilization | 미셀 내부에 난용성 물질을 용해시키는 현상. |
| **분산** | Dispersion | 고체 입자를 액체 중에 균일하게 현탁시키는 공정. |

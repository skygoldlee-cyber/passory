## 1. 매핑 원칙

1. **참조자료가 구조적 기준**: 참조자료의 구성을 기본으로 교재가 작성된다.
2. **교재는 학습용 압축 구조**: 교재는 참조자료의 모든 섹션을 1:1로 복사하지 않고, 관련 섹션을 그룹화하여 학습 단위로 압축한다.
3. **섹션 번호체계 준수**: 교재는 `docs/exams/cosmetic/reference/NUMBERING_SYSTEM.md`의 십진법 체계를 따른다.
4. **표준형/이야기형 구조 일치**: 두 형식은 동일한 섹션 수와 그룹화를 유지한다.

## 4. 압축 방식

교재는 참조자료의 여러 섹션을 하나의 `## N.` 섹션으로 그룹화한다:

- 관련 주제를 하나의 학습 단위로 통합
- `## N.` (Chapter 내 섹션) → `### N.` (소섹션) → `#### N.M` (세부항목) → `##### N.M.K` (상세항목)
- 표준형과 이야기형은 동일한 섹션 구조를 유지
- 이야기형은 `### 📖 상황` 등 스토리 헤딩을 예외적으로 허용

## 1. 번호체계 개요

### 1.1 설계 원칙

1. **헤딩 기반**: 모든 구조적 레벨은 Markdown 헤딩(`###`, `####`, `#####`)으로 표현
2. **십진법 번호**: `N.`, `N.M`, `N.M.K` 형식으로 위계를 숫자로 표현
3. **목차 연동**: `###`와 `####`는 PWA 사이드바 목차에 표시
4. **본문 분리**: 세부 항목(`①`)과 설명(`•`)은 헤딩이 아닌 본문 텍스트
5. **챕터별 리셋**: `##`(대단원)마다 `###` 번호가 1부터 재시작

### 1.2 체계 전환 이력

| 시기 | 체계 | 비고 |
|---|---|---|
| 초기 | `(N)` / `①` / `가.` / `A.` / `a.` / `1)` / `①` | 7가지 기호 혼용 |
| 1차 개선 | `(N)` / `①` / `가.` / `1.` / `-` / `**굵게**` | 4가지 기호로 단순화 |
| **현재** | `N.` / `N.M` / `N.M.K` / `①` / `•` | **십진법 + 헤딩 유지** |

## 2. 번호체계 규칙

### 2.1 헤딩 레벨별 번호 형식

| 레벨 명칭 | 헤딩 | 번호 형식 | 의미 | 예시 | 목차 표시 |
|---|---|---|---|---|---|
| Chapter | `##` | `N.` (챕터 번호) | 과목 내 대단원 | `## 1. 화장품법의 목적과 법령 체계` | O (Chapter) |
| Section | `###` | `N.` | Chapter 내 1차 항목 | `### 1. 화장품법의 입법 취지` | O (섹션) |
| Subsection | `####` | `N.M` | Section의 하위 항목 | `#### 1.1 용어의 정의` | O (하위, 접기/펼치기) |
| Detail | `#####` | `N.M.K` | Subsection의 세부 항목 | `##### 1.1.1 유지` | X (목차에 표시 안 됨) |

> **⚠️ `##`와 `###`의 번호 중복 주의**
>
> `##`와 `###`이 모두 `N.` 형식을 사용하므로 번호만 보면 충돌이 있습니다.
> 파일 내 구조에는 문제가 없지만(헤딩 레벨로 구분됨), 문서 작성 시 혼동을 피하기 위해
> 다음 원칙을 준수합니다:
>
> 1. **`##`는 챕터 단위**: `## 1.`, `## 2.`, ... (과목 전체 기준)
> 2. **`###`는 섹션 단위**: 각 `##`마다 `### 1.`, `### 2.`, ... (챕터 내 기준, 리셋)
> 3. **구분은 헤딩 레벨로**: 번호가 같아도 `##`와 `###`는 다른 레벨
>
> ```markdown
> ## 1. 화장품법의 목적과 법령 체계     ← Chapter 1
> ### 1. 화장품법의 입법 취지           ← Section 1 (Chapter 1 내)
> ### 2. 법령 체계                      ← Section 2 (Chapter 1 내)
> ## 2. 화장품의 정의                   ← Chapter 2
> ### 1. 화장품의 정의 및 유형          ← Section 1 (Chapter 2 내, 리셋)
> ```

### 2.2 본문 레벨 번호 형식

| 용도 | 기호 | 역할 | 예시 | 목차 표시 |
|---|---|---|---|---|
| 핵심 항목 | `①` `②` `③` ... | **내용 단위** (병렬적 핵심 항목) | `① 화장품제조업` | X |
| 부연 설명 | `•` | **설명 단위** (①의 하위 부연) | `• 시설기준 충족 후 등록` | X |
| 강조 | `**굵게**` (기호 없음) | 제목/키워드 강조 | `**벌칙**` | X |

> **📌 `①`과 `•`의 사용 규칙 (엄격)**
>
> - `①` = **내용 단위**: 병렬적인 핵심 항목 (예: 영업 3종, 결격사유 5가지)
> - `•` = **설명 단위**: `①` 항목의 부연 설명
> - `가.` `나.` = **사용하지 않음** (구 체계 잔재)
> - `**굵게**` = 기호 없이 강조만
>
> ```markdown
> ① 화장품제조업
> • 화장품을 제조하는 영업이다.
> • 시설기준을 갖추어 등록해야 한다.
>
> ② 화장품책임판매업
> • 품질관리 및 책임판매 업무를 수행한다.
> • 책임판매관리자를 두어야 한다.
> ```

### 2.3 완전한 예시

```markdown
## 1. 화장품법의 목적과 법령 체계

### 1. 화장품법의 입법 취지(목적)

> 📌 **출처**: 화장품법 제1조

본문 설명...

#### 1.1 법령 체계

본문 설명...

##### 1.1.1 법령 위계

| 구분 | 법령 |
|---|---|
| 법률 | 화장품법 |
| 시행령 | 화장품법 시행령 |

#### 1.2 영업의 종류

① 화장품제조업
• 화장품을 제조하는 영업이다.
• 시설기준을 갖추어 등록해야 한다.

② 화장품책임판매업
• 품질관리 및 책임판매 업무를 수행한다.
• 책임판매관리자를 두어야 한다.

③ 맞춤형화장품판매업
• 맞춤형화장품을 혼합·소분하여 판매한다.
• 맞춤형화장품조제관리사를 두어야 한다.
```

## 3. 번호 할당 규칙

### 3.1 리셋 규칙

| 헤딩 | 리셋 시점 | 예시 |
|---|---|---|
| `### N.` | `##`마다 1부터 재시작 | `## 1.` → `### 1.`, `## 2.` → `### 1.` |
| `#### N.M` | `###`마다 M이 1부터 재시작 | `### 1.` → `#### 1.1`, `### 2.` → `#### 2.1` |
| `##### N.M.K` | `####`마다 K가 1부터 재시작 | `#### 1.1` → `##### 1.1.1`, `#### 1.2` → `##### 1.2.1` |

### 3.2 본문 번호 규칙

| 기호 | 역할 | 리셋 시점 | 비고 |
|---|---|---|---|
| `①②③` | **내용 단위** (핵심 항목) | `####`마다 1부터 권장 | 참조용(`①, ② 중 하나`)은 줄바꿈 불필요 |
| `•` | **설명 단위** (①의 부연) | 줄바꿈 없이 자유 사용 | `①` 아래에만 사용 권장 |
| `**굵게**` | 강조 | 제한 없음 | 기호 없이 제목/키워드 강조 |

> **주의**: `①`은 핵심 항목(내용 단위), `•`는 그 설명(설명 단위)으로 역할을 고정한다.
> `•`를 단독 핵목으로 사용하거나 `①`을 설명으로 사용하지 않는다.

### 3.3 금지 사항

- **잘린 헤더**: `#### ① 화장품제조업 또는 ...` (끝에 `...` 금지)
- **헤더-본문 중복**: 헤더 제목과 다음 줄 본문이 같은 내용
- **`###` 없이 `####`**: `##` 아래 `###`를 건너뛰고 `####` 금지
- **구 체계 잔재**: `### (N)`, `#### ①`, `##### 가.`, `#### 0.N` 금지
- **본문 기호 헤더 사용**: `### ①`, `#### ①` 금지 → `### N.`, `#### N.M` 사용
- **본문 강조 기호**: `**A. xxx**`, `**가. xxx**` 금지 → `**xxx**` 사용
- **본문 목록 알파벳**: `a. b. c.` 금지 → `① ② ③` 사용

### 3.4 보조 헤더 예외 규칙

학습 교재의 구조상 번호가 없는 보조 헤더를 예외적으로 허용한다.

| 유형 | 헤딩 | 위치 | 예시 |
|---|---|---|---|
| 학습 안내 | `###` | 챕터 시작 | `### 학습 목표`, `### 학습 흐름`, `### 출제 빈도 높은 영역` |
| 빈출 요약 | `###` | `## 📌 용어 정리` 아래 | `### 법령 체계`, `### 영업 3종 (빈출 최상위)` |
| 플래시카드 | `###` | `## 🧠 30초 회상` 아래 | `### CARD 01 — 법령 위계` |
| 확인문제 | `###` | `## ✅ 확인문제` 아래 | `### 확인문제` |
| 참고/비교 | `####` | 본문 내 보조 설명 | `#### 참고: 개인정보가 아닌 정보`, `#### 비교: 개인정보 보호 적용` |
| 기타/관련 | `####` | 본문 내 보조 설명 | `#### 기타 화장품 유형`, `#### 관련 용어` |

> **📌 보조 헤더 판단 기준**
>
> 1. **학습 내용이 아닌 구조적 요소**: 학습 목표, 빈출 요약, 플래시카드 등
> 2. **본문 내 보조 설명**: 참고, 비교, 기타, 관련 등
> 3. **이모지 헤더**: `### 🎯 한 줄 핵심`, `### 📖 민수의 상황` 등
>
> 이 헤더들은 번호체계 대상이 아니며, 목차에서도 본문 섹션과 구분하여 표시된다.

## 4. PWA 목차 연동

### 4.1 목차 표시 범위

```
사이드바 목차
├── 📖 Chapter 01. 화장품법의 이해      ← ## (항상 표시)
│   ├── ▸ 1. 화장품법의 입법 취지        ← ### (표시)
│   │   ├── 1.1 법령 체계               ← #### (접기/펼치기)
│   │   └── 1.2 영업의 종류             ← #### (접기/펼치기)
│   └── ▸ 2. 화장품의 정의              ← ### (표시)
│       └── 2.1 화장품의 정의           ← #### (접기/펼치기)
└── 📖 Chapter 02. 개인정보 보호법
```

### 4.2 TOC 레벨 판정 로직

`src/views/textbook-reader.js`의 `_getTocLevel()`:

```javascript
function _getTocLevel(title) {
    const t = (title || '').trim();
    if (/^\d+\.\d+\.\d+/.test(t)) return 3;   // 1.1.1 (3단계)
    if (/^\d+\.\d+/.test(t)) return 2;         // 1.1 (2단계)
    if (/^\d+\./.test(t)) return 1;           // 1. (1단계)
    return 0;                                  // Chapter 등
}
```

### 4.3 헤딩 추출 로직

`_extractSubHeadings()`:

- `### ` 헤딩 → level 3 (목차에 표시)
- `#### ` 헤딩 → level 4 (목차에 표시, 접기/펼치기)
- `##### ` 헤딩 → **목차에 표시되지 않음**

### 5.3 표준형-이야기형 동기화

- 표준형과 이야기형은 **동일한 번호 체계** 유지
- 같은 섹션 번호(`### N.`, `#### N.M`) 사용
- 이야기형에만 있는 서사(`#### 📖 민수의 상황`)는 번호체계에서 제외

## 7. 학습용 압축 구조 원칙 (2026-09-14)

### 7.1 원칙

1. **참조자료가 구조적 기준**: 참조자료(`content/exams/cosmetic/참조자료/`)의 구성을 기본으로 교재가 작성된다.
2. **교재는 학습용 압축 구조**: 교재는 참조자료의 모든 섹션을 1:1로 복사하지 않고, 관련 섹션을 그룹화하여 학습 단위로 압축한다.
3. **전 과목 일관성**: 모든 과목이 학습용 압축 구조를 사용한다.
4. **표준형/이야기형 일치**: 두 형식은 동일한 섹션 수와 그룹화를 유지한다.

### 7.2 압축 방식

교재는 참조자료의 여러 `## N.` 섹션을 하나의 `## N.` 섹션으로 그룹화한다:

- 관련 주제를 하나의 학습 단위로 통합
- 압축 시 `## N.` → `### N.` (강등), `### N.` → `#### N.M` (강등), `#### N.M` → `##### N.M.K` (강등)
- 섹션 번호는 챕터마다 리셋, 소섹션 번호는 섹션마다 리셋

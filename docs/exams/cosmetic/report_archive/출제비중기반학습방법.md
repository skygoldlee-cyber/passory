## 1. 핵심 원칙: 비중이 높은 항목부터, 편차가 큰 항목은 집중 공략

출제비중 분포 조사 결과, **예상 출제 비중**과 **문제은행 실제 분포** 사이에 유의미한 편차가 확인되었습니다. 효율적인 합격을 위해서는 다음 두 가지를 동시에 고려해야 합니다.

| 전략 축 | 의미 | 적용 방법 |
|---------|------|-----------|
| **비중 우선** | 예상 출제 비중이 높은 항목을 먼저 학습 | ★★★★★ 항목 → ★★★★ → ★★★ 순으로 |
| **편차 보정** | 문제은행 분포가 예상 비중과 크게 다른 항목을 집중 보완 | 과소 항목은 추가 학습, 과다 항목은 감량 |

## 9. 객관식 vs 단답형 유형별 대비 전략

> 시험은 객관식 80문항 + 단답형 20문항으로 구성됩니다. 유형별 학습 접근법이 다릅니다.

### 유형별 출제 구조

| 과목 | 객관식 | 단답형 | 단답형 비율 | 단답형 특징 |
|:----:|:------:|:------:|:-----------:|------------|
| 1 | 7 | 3 | 30% | 법령 용어, 숫자, 기관명 등 단답 암기형 |
| 2 | 20 | 5 | 20% | 원료명, 기준값, 공정 용어 등 |
| 3 | 25 | 0 | 0% | 단답형 없음 — 전부 객관식 |
| 4 | 28 | 12 | 30% | **단답형 12문항으로 최다** — 피부 구조, 혼합 비율, 기구명 등 |

### 객관식 대비 전략

```
보기(①~⑤)에서 정답을 고르는 유형
    → 키워드 인식 + 오답 소거법 위주
```

| 전략 | 내용 |
|------|------|
| **키워드 인식** | 문제의 핵심 단어만 보고도 정답 유추 가능하도록 반복 노출 |
| **오답 소거** | 명백히 틀린 보기를 먼저 지우는 연습 — 5지선다에서 2개 소거 시 33% 확률 |
| **함정 파악** | "옳지 않은 것", "틀린 것" 부정형 문제 표시 습관화 (밑줄 필수) |
| **숫자 함정** | 비슷한 숫자(15일/15초, 97%/95%) 보기 섞기 출제 패턴 대비 |

### 단답형 대비 전략

```
빈칸에 정답을 직접 입력하는 유형
    → 정확한 용어 암기 + 철자 오류 주의
```

| 전략 | 내용 |
|------|------|
| **정확한 용어 암기** | 객관식은 보기에서 인식하면 되지만, 단답형은 **스스로 정확히 써야 함** |
| **핵심 키워드 암기** | 교재의 ⭐ 한 줄 핵심, 🎯 출제 포인트를 단답형 카드로 재작성 |
| **부분 점수 확인** | 완전히 틀려도 부분 점수가 있을 수 있으니 아는 만큼 작성 |
| **과목4 단답형 집중** | 단답형 12문항 중 과목4가 차지하므로 **4과목 용어 암기 최우선** |

## 10. 문제은행 교재인용(L###) 활용 방법

> 문제은행 파일(`과목N_기출문제_교재인용.md`)의 각 정답에는 **교재 라인 번호(L###)**가 표기되어 있습니다. 이를 활용하면 틀린 문제의 교재 원문을 즉시 찾아 재학습할 수 있습니다.

### 활용 절차

```
문제은행 풀이 → 오답 확인 → 정답의 L### 확인 → 교재 파일 해당 라인 이동 → 원문 재학습
```

### 과목별 교재 파일 ↔ 문제은행 매핑

| 과목 | 교재 파일 | 문제은행 파일 | 교재인용 형식 |
|:----:|----------|--------------|:------------:|
| 1 | `교재/1과목_화장품법의이해_표준형.md` | `문제은행/과목1_문제은행.md` | `교재: L###` |
| 2 | `교재/2과목_제조및품질관리_표준형.md` | `문제은행/과목2_문제은행.md` | `교재: L###` |
| 3 | `교재/3과목_유통화장품안전관리_표준형.md` | `문제은행/과목3_문제은행.md` | `교재: L###` |
| 4 | `교재/4과목_맞춤형화장품의이해_표준형.md` | `문제은행/과목4_문제은행.md` | `교재: L###` |

### 오답 역추적 학습법

1. 문제은행 풀이 후 오답을 표시
2. 오답의 정답 블록에서 `교재: L####` 번호 확인
3. 교재 파일에서 해당 라인으로 이동 (에디터 Ctrl+G 또는 검색)
4. 교재 원문 + 전후 10줄 정독
5. 해당 섹션의 마인드맵/표 함께 확인
6. 오답 노트에 "L####: [핵심 내용]" 형태로 기록

> 💡 **과소 항목(2.3, 4.6, 3.3 등)은 문제은행 자체가 부족**하므로, 교재 본문의 🎯 출제 포인트와 📝 확인문제를 직접 풀어 단답형/객관식 대신 활용

## 13. 과목별 최소 합격선(40%) 고려 전략

> 합격 조건은 **전체 60%(600점) 이상** + **각 과목 만점의 40% 이상**입니다. 과목별 40%를 못 넘기면 전체 점수가 높아도 불합격입니다.

### 과목별 최소 합격선

| 과목 | 만점 | 40% 선 | 최소 정답 수 | 위험도 |
|:----:|:----:|:------:|:------------:|:------:|
| 1 | 100점 | 40점 | 4/10문항 | **높음** (문항 수 적어 1문항당 10점) |
| 2 | 250점 | 100점 | 10/25문항 | 중간 |
| 3 | 250점 | 100점 | 10/25문항 | 중간 |
| 4 | 400점 | 160점 | 16/40문항 | 낮음 (문항 수 많아 분산) |

### 과목별 위험 관리

| 과목 | 위험 요인 | 대응 전략 |
|:----:|-----------|-----------|
| **1** | 10문항만 있어 1문항당 10점 — **6문항 이상 맞춰야 안전** | 1.1 화장품법(80~85%) 완벽 학습으로 7~8문항 확보 |
| **2** | 25문항, 사용제한 원료(25~30%) 학습 부족 시 위험 | 2.3 집중 보완으로 최소 10문항 확보 |
| **3** | 25문항, 전부 객관식 — 작업장 위생(61%)에만 의존하면 위험 | 3.3/3.2 보완으로 안전망 확대 |
| **4** | 40문항으로 분산 효과 있으나 단답형 12문항 비중 높음 | 단답형 대비 용어 암기 필수, 4.6 보완으로 20문항 이상 확보 |

> ⚠️ **과목1이 가장 위험** — 10문항 중 6문항 이상 맞추려면 1.1 화장품법(8~9문항 예상)에서 최소 6문항, 1.2 개인정보보호법(1~2문항 예상)에서 최소 0~1문항 확보 필요

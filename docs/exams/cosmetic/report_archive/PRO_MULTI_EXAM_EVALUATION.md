**질문**: Learning Premium(Pro) 기능이 여러 자격증 시험의 킬러 피처가 될 수 있는가?

**결론**: 조건부 가능. Pro 로직 자체는 시험 무관하게 재사용 가능하지만, "킬러 피처"가 되려면 로직보다 **콘텐츠 연결 루프**가 진짜 차별점이다.

---

## 1. 기술적 이식성 — 이미 확보

콘텐츠 독립성 강화(2026-09-25)로 Pro 로직의 입력 계약이 정리됐다:

```
manifest 선언 (과목·규칙·문항배율) → registry → STUDY_DATA(cards/quizzes/chapters)
                                          ↓
                  Pro 엔진: 추천·진단·D-day·패턴분석·예상점수·통합검색
```

- 합격 규칙(`passAverage`/`subjectFailBelow`)·과목 구성·문항 수가 매니페스트 선언 — **새 시험 = 콘텐츠 폴더 + manifest.json만으로 Pro 전 기능 동작**
- `scopedKey`로 진도 격리, `hasFeature`로 도메인 특화 기능(성분사전 등) 자동 게이팅
- 섹션 딥링크는 제목 직접 매칭 — 교재 챕터 명명 규칙과 무관
- 남은 결합도: 카드/퀴즈에 `term·definition·question·options` 스키마 필요 — 기존 파서 계약이라 이미 표준

| 기능 | 범용성 | 차별성 | 평가 |

## 3. 리스크

- **룰 기반 추천의 한계**: 경쟁사(산타·뤼이드 계열)는 수만 명 데이터로 정밀화. 단일 사용자 로컬 데이터만으로는 추천 정확도 상한 존재 — "AI" 표방은 과장
- **콘텐츠가 병목**: Pro 엔진은 재사용되지만 시험마다 교재 MD·문제은행·인용 라인을 파이프라인 규격으로 제작해야 함 — **시험당 콘텐츠 제작 공수가 확장의 실제 비용**
- **인용 루프 없으면 평범**: 오답이 조문 원문 라인까지 추적되지 않으면 "괜찮은 플래시카드 앱" 중 하나

## 4. 적합한 시험 유형

| 적합도 | 유형 | 예 |
|---|---|---|
| ✅ 높음 | 법령·수치·조문 암기형 객관식 | 조제관리사 계열, 식품기사, 위생사, 보세사, 관세사, 소방설비기사 |
| 🟡 중간 | 개념+계산 혼합 | 전기기사, 정보처리기사 (계산 훈련 확장 필요) |
| ❌ 낮음 | 실기·서술형 중심 | 실기 시험, 논술 |

공통 조건: 객관식 문제은행 + 본문 참조 가능한 교재 존재.

## 5. 킬러 피처로 키우기 위한 액션

1. **인용 루프를 전면에**: Pro 가치 제안을 "개인화 추천"이 아니라 "틀린 문제가 교재 조문 원문까지 연결되는 학습"으로 재정의
2. **시험 2개로 검증**: cosmetic 외 법령 암기형 시험 1개 추가 → 엔진 재사용 + 지불 의사 실측
3. **자가 보고 데이터 축적**: `actual_exam_result` 수집이 쌓이면 실측 합격 예측 가능 — 플랫폼 고유 데이터는 경쟁사가 따라올 수 없는 자산
4. **추천 정밀화**: 수집 데이터로 룰 가중치 조정 — 지표로 증명

## 요약

Pro 로직은 멀티시험 이식 준비 완료. 그러나 기능 목록 자체는 차별화가 아닌 기본기이며, 킬러 피처 후보는 ① 문제↔교재 라인 인용 루프, ② 오프라인 완전 동작, ③ (데이터 축적 후) 실측 합격 예측의 조합이다. 확장의 병목은 로직이 아니라 **시험당 콘텐츠 제작**이다.

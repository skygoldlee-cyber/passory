## 리뷰 핵심 주장

1. **Premium 서사 순서 재정의** — "개인화 → 추천 → 예측"이 아니라
   "콘텐츠 연결 → 학습 데이터 → 개인화 → 예측" 순이 실제 경쟁력과 일치
2. **문제↔교재 인용 루프를 최우선 차별화로** — 문제→오답→교재 L###→핵심 문장→관련 개념→카드→유사문제→재시험까지 확장하면 "시험 지식 그래프"
3. **시험당 콘텐츠 제작시간을 KPI로** — 멀티시험 확장성을 "공수 시간"으로 객관화
4. **합격 예측은 서두르지 말 것** — 예상 점수 한정 → 실측 축적 → 보정 순서 유지 (현 구현과 일치)
5. **추천은 "AI"가 아니라 "근거"로 설득** — 왜 이걸 추천했는지 이유 표시
6. **사용자용 한 문장 정의 필요** — 상품 언어 부재
7. **두 번째 시험 추가는 사업 확장이 아니라 아키텍처 검증**

# 리뷰 #2 — LEARNING_PREMIUM_PLAN 대상 (수신: 2026-09-26)

## 리뷰 핵심 주장

1. **"기능을 넣을 것인가"는 정리됐지만 "왜 돈을 내는가"는 미증명** — 기능 중심 계획 → 유료 가치 검증 계획으로 전환 필요
2. **B1을 "AI 맞춤"이라 부르지 말 것** — 실제는 규칙 기반 추천. 초기엔 "개인 학습 데이터 기반 우선순위 추천"으로 표기하는 편이 신뢰성 높음
3. **인용 루프를 B5/C0로 승격** — 오답→교재 L###→핵심 문장→관련 개념→카드→유사문제→재시험 완성 시 "틀린 순간 이해하고 맞힐 때까지 안내하는 시스템"
4. **"구현 완료"와 "사업 검증 완료"를 분리 표로 추적** — 기능×개발×사용률×만족도×유료가치
5. **통합검색은 유료 근거 ★★ 수준** — UX는 좋지만 지불 동기로는 보조
6. **D(결제)는 가치 검증 후로 지연** — 검증 전 인프라 구축은 비용 선행
7. **B1~B4를 "합격 루프"로 통합 서사화** — B2(어디가 약한지)→B4(왜 약한지)→B1(뭘 공부할지)→B3(언제까지 얼마나)
8. **콘텐츠 제작시간이 최대 사업 리스크** — AI 활용으로 공수 절감률까지 측정 권장
